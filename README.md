# Démo « directeur de jeu » (KN2000)

Démonstrateur Web MIDI : les accords joués sur un clavier pilotent la lecture d'un style — reconnaissance d'accords à l'entrée, position dans la progression, lecture des patterns d'un catalogue digéré (style « test »), changements de section aux frontières de mesures.

👉 Ouvrir `index.html` (servi par GitHub Pages, branche `gh-pages`), choisir les ports MIDI in/out, cliquer sur ▶ Start, passer en mode Follow et jouer Cmaj7 / Am7 / Dm7 / G7.

Compatible Chrome/Edge desktop (Web MIDI).
