Moteur générique + banque de styles externe : le style actif est chargé depuis un fichier <id>.js (contrat window.STYLE_DATA), choisi par ?style=<id> dans l'URL, le sélecteur, ou le 1er du manifeste styles.js ; les boutons de sections sont générés depuis le style. Source des styles (v3.14) : par défaut le dossier relatif styles/ à côté de la page ; sinon une URL (ex. mini serveur local https://IP-du-PC:8734/styles/, les fichiers y sont servis en statique, aucune modif serveur) ; ou des fichiers locaux choisis via 📁 (gardés en localStorage). Priorité : fichiers locaux > URL > dossier relatif. Mode Follow : le changement d'accord s'applique dès la pulsation suivante (sans délai), en ne modifiant que la hauteur des notes : jamais le nombre ni les instants des notes envoyées (note-off appariés aux note-on). « attendu » = prochain accord de la progression démo (I–vi–ii–V, surchargeable par le style via prog). Reconnaissance : table JazzLab, debounce 30 ms dès 3 notes + photo de l'accord. v3.13 = split moteur/banque de styles. v3.12 = application immédiate, substitution de hauteur sans aucune note ajoutée. Si la version affichée n'est pas v3.14, vide le cache (Ctrl+F5).
